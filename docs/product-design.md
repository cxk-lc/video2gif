# 产品设计文档 · 视频转GIF动图

> 版本：v0.1 ｜ 日期：2026-10-15 ｜ 状态：已确认（2026-10-15）  
> 用途：确定本版本"做什么 / 暂时不做什么"，作为技术设计与实现开发的统一依据（施工图）。  
> 原则：简短优先——梳理整体方向与主要功能即可，细节留给迭代。

## 1. 一句话定位

一个 Windows 本地桌面小工具：把常见视频（MP4 / AVI / MOV 等）的指定片段，按自定义帧率、尺寸、速度与质量参数转换为可循环播放的 GIF 动图——先预览、满意后再保存到本地。

## 2. 核心用户路径（主流程）

1. 双击启动脚本打开软件窗口；
2. 点「选择视频」导入本地视频（文件选择对话框，支持 MP4 / AVI / MOV 等常见格式）；
3. 软件自动读取并显示视频信息（时长 / 分辨率 / 原始帧率），起止时间默认填为全片；
4. 用户设定参数：截取起止时间、输出帧率、输出宽度（高度默认等比自动）、播放速度、质量档位（颜色数）；
5. 点「开始转换」→ 进度条实时更新，状态文字提示当前阶段；转换中可随时取消；
6. 转换完成后，预览区自动循环播放生成的 GIF（等比缩放显示）；
7. 满意 → 点「保存到…」选择位置导出 GIF；不满意 → 调参后重新转换。

## 3. 本版本功能清单（MVP）

| 功能     | 说明                                                                              | 优先级 |
| ------ | ------------------------------------------------------------------------------- | --- |
| 导入视频   | 原生文件选择对话框；支持 MP4/AVI/MOV/WMV/MKV/WebM/FLV 等 ffmpeg 可解码格式；显示已选文件名                | 必须  |
| 视频信息读取 | 显示时长、分辨率、原始帧率；非视频/损坏文件给出明确中文错误                                                  | 必须  |
| 片段时间设定 | 起始 / 结束时间输入框，支持 `秒`、`mm:ss.ms`、`hh:mm:ss.ms` 三种写法；自动校验（结束>起始、不超过视频时长，超出自动截断并提示） | 必须  |
| 输出帧率   | 1–30 fps，默认 12 fps                                                              | 必须  |
| 输出尺寸   | 输出宽度（px，默认取原宽），高度默认等比自动；可手填高度                                                   | 必须  |
| 播放速度   | 0.25×–4×，默认 1×                                                                  | 必须  |
| 压缩质量   | 质量档位（高/中/低，映射 GIF 调色板颜色数 256/128/64）+ 颜色数微调（2–256）                              | 必须  |
| 循环播放   | GIF 默认无限循环（可选循环次数：0=无限）                                                         | 必须  |
| 转换进度显示 | 百分比进度条 + 状态文字（解析 ffmpeg 实时输出，含两遍调色板阶段的阶段提示）                                     | 必须  |
| 取消转换   | 转换中可取消；安全终止转换进程并清理临时文件，界面回到可操作状态                                                | 必须  |
| 错误提示   | 文件损坏/编码不支持/参数非法/输出不可写/转换失败 → 中文可读提示，附「详情」可查看原始报错                                | 必须  |
| 结果预览   | 转换完成后窗口内自动循环播放生成 GIF；等比缩放显示，不改变实际输出尺寸                                           | 必须  |
| 保存到本地  | 「保存到…」另存为对话框；默认文件名 = 视频名 + 时间段；保存后可「打开所在文件夹」                                    | 必须  |

- 记忆上次参数 / 配置文件。

## 5. 边界条件与约束

- **运行平台**：Windows 10/11 桌面。本机隔离 Python 不含 tkinter，故使用由本机 conda Python 派生的项目专用 venv（已实测 tkinter 可用）。
- **ffmpeg**：转换引擎二进制随项目目录携带（不依赖系统安装、不改 PATH、不写注册表）。
- **大输出保护**：长视频 + 高帧率 + 大尺寸会产出数十 MB 的 GIF；转换前给出软提示（预估时长/帧数），不强制拦截。
- **路径兼容**：视频路径与保存路径含中文、空格、特殊字符必须正常工作（Windows 常见场景）。
- **参数容错**：时间输入容忍 `1:23.5` 等写法；非法输入给出行内红字提示，不弹窗轰炸。
- **状态一致性**：转换中禁用重复触发与参数修改；取消/失败后界面必须回到可再次操作状态；临时文件自动清理。
- **异常兜底**：任何未预期异常都不得让窗口卡死或崩溃退出（捕获并提示）。

## 6. 验收要点

> 从"做什么 / 不做"提炼为可检查的验收条件（"完成" = 全部满足）。

- [ ] 双击启动脚本可正常打开窗口，无控制台报错；
- [ ] 分别导入 MP4 / AVI / MOV 文件，均能读出示时长与分辨率，起止时间自动填充；
- [ ] 设定起止时间转换后，GIF 实际时长 ≈（结束−起始）÷ 速度（允许 ±1 帧误差）；
- [ ] 帧率 / 宽度 / 速度 / 质量档位改动后效果可感知且方向正确；
- [ ] 生成的 GIF 在系统看图工具与浏览器中都能自动循环播放；
- [ ] 转换过程中进度条与状态文字持续更新；点「取消」能立即停止且界面恢复可用；
- [ ] 非法输入（结束早于起始、时间格式错、选了非视频文件）均出现中文提示且不崩溃；
- [ ] 预览区可正常循环播放；「保存到…」导出的文件与预览一致且可正常打开；
- [ ] 路径含中文与空格的视频，转换与保存全程正常；
- [ ] 转换失败场景（如故意选损坏文件）有明确错误提示，且可查看详情。
