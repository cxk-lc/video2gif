# 视频转GIF动图 v0.1.1 · Windows 免环境版

把视频片段转换为**可循环播放的 GIF 动图**：截取片段、调帧率 / 尺寸 / 速度 / 质量，先预览、再保存。

**下载即用**：单个 exe，无需安装 Python 或 ffmpeg；全程本地处理、不联网、不上传任何数据。

## 下载与运行

- 下载下方资产 `VideoGif-v0.1.1-win64.exe`
- 双击运行（首次启动需解压自身，约 2–5 秒属正常）
- 系统要求：Windows 10 / 11 x64

## 功能一览

- 导入 MP4 / AVI / MOV / MKV / WMV / WebM / FLV 等常见格式
- 设定截取片段的起止时间（支持 `秒` / `mm:ss` / `hh:mm:ss`）
- 输出帧率（1–30 fps）、输出宽度 / 高度（默认等比自动）
- 播放速度 0.25×–4×；质量档位（高 / 中 / 低）与颜色数微调（2–256）
- 循环次数可调（0 = 无限循环）
- 转换进度实时显示、可随时取消；完成后窗口内自动循环预览
- 「保存到…」导出 GIF；「打开所在文件夹」直达文件

## 说明与注意事项

- exe 内嵌 ffmpeg 7.1 转换引擎（GPL 许可，构建来自 gyan.dev），因此体积较大。
- 若杀毒软件误报：PyInstaller 打包程序的常见误报，请添加信任后使用。
- 本版本与已验收的 v0.1.0 功能一致；新增：免环境单文件打包、窗口图标、标题栏版本号。
